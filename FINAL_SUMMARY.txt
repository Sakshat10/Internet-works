WHAT STUDENTS WILL LEARN:
--------------------------------------------------------------------------------

✓ Internet is a network of networks (not one computer)
✓ Internet ≠ Wi-Fi
✓ History: ARPANET → TCP/IP → WWW → Today
✓ Components: Device, Router, ISP, Internet, Server
✓ IP addresses identify devices (like home addresses)
✓ DNS translates names to IP addresses (Internet's phonebook)
✓ Data breaks into packets for efficient transmission
✓ Packets take different routes and reassemble at destination
✓ Encryption protects data (lock/unlock)
✓ Complete journey happens in milliseconds
